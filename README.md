# jpomop

Convert Japanese DPC inpatient data (Form 1 and the EF file) to the OMOP Common Data Model v5.4.

jpomop is built only from the public specification published by the Ministry of Health, Labour and Welfare, and is tested only on synthetic data generated by this repository. It ships no hospital data and no code masters.

**Status:** early development. Nothing here is usable yet. The plan for v0.1 (end of November 2026):

- read and validate DPC Form 1 (様式1) and the EF integrated file (入院EF統合ファイル) against the FY2026 specification
- write seven CDM tables: `person`, `visit_occurrence`, `visit_detail`, `condition_occurrence`, `procedure_occurrence`, `drug_exposure`, `death` (plus `observation_period`)
- build the vocabulary locally from code masters that each user downloads, and report mapping rates per domain
- a fixed synthetic dataset (about 100 patients) so that anyone can run the conversion without real data

## Code masters are not included

The disease, procedure and drug masters (基本マスター) are published by the 医療情報基盤・診療報酬審査支払機構, whose terms do not allow redistribution. Download them yourself from
https://www.hpdx.or.jp/seikyushiharai/tensuhyo/kihonmasta/index.html
and point jpomop at the folder. Instructions will be added with the vocabulary builder.

## 日本語

厚生労働省が公開している DPC 調査の仕様（様式1・入院EF統合ファイル）だけを元に、DPC データを OMOP CDM v5.4 へ変換する Python のプログラムです。病院の実データとマスターは含みません。動作確認には、このリポジトリで作る架空データだけを使います。開発中のため、まだ使える状態ではありません。

マスターは、医療情報基盤・診療報酬審査支払機構のサイトから各自でダウンロードしてください。
